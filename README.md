# DATAIKOS LEARN

**De l’idée au dossier bancable**  
Outil d’analyse stratégique pour ingénieurs, chercheurs, consultants et incubateurs.  
Structurez, chiffrez, simulez et exportez votre projet en un dossier professionnel prêt à présenter.

**Accédez à l’outil en ligne : [dataikoslearn.vercel.app](https://dataikoslearn.vercel.app)**

---

## Fonctionnalités

- **Pré‑Test** : diagnostic de votre profil entrepreneur (opérationnel, IA/chiffrage, en construction).
- **Market Fit Canvas** : 6 blocs pour clarifier problème, solution, valeur, canaux, prix, coûts.
- **Business Probability Canvas (BPC)** : chiffrage complet : équipements, personnel, coûts variables, charges fixes, produits, marché, rentabilité, seuil de rentabilité, LTV/CAC.
- **Simulateur de traction** : projection sur 6 mois selon 4 scénarios de croissance (prudent, régulier, coups, plateau) + **10 stress‑tests** pour anticiper les chocs.
- **Rapport exhaustif** : compilation automatique de toutes les données.
- **Exports PDF** : BPC, rapport, simulation ou dossier complet.
- **Master Prompts** intégrés pour interagir avec un LLM (copiez‑les et obtenez des suggestions personnalisées).

## Installation locale (pour contributeurs)

Si vous souhaitez exécuter l’outil en local ou contribuer au code :

1. **Prérequis** : un navigateur moderne.
2. **Téléchargez** le dépôt :
   ```bash
   git clone https://github.com/aatndongodavid/DATAIKOSLEARN.git
   cd datakos-learn
   ```
3. **Placez** le fichier `dataikoslearn.png` (logo) dans le même dossier que `index.html`.
4. **Ouvrez** `index.html` dans votre navigateur.

## Utilisation de l’outil en ligne

1. Accédez à [dataikoslearn.vercel.app](https://dataikoslearn.vercel.app)
2. Suivez le parcours recommandé depuis la page d’accueil, ou naviguez directement vers l’outil de votre choix via la barre latérale.
3. Remplissez les champs des différents modules, les données sont conservées localement pendant votre session.
4. Utilisez les *Master Prompts* pour solliciter un LLM (ChatGPT, Claude, etc.) et enrichir votre réflexion.
5. Visualisez les résultats de rentabilité, le simulateur, puis générez vos rapports en PDF.
6. Exportez également vos données brutes au format JSON pour les sauvegarder ou les réimporter.
